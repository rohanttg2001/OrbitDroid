From download to first launch

Your installation guide.

Check your Mac chip

Open Apple menu → About This Mac. Choose the matching Apple silicon or Intel download.

Extract the app ZIP

Double-click the downloaded ZIP in Finder. Locate OrbitDroid.app inside the extracted files.

Move to Applications

Drag OrbitDroid.app into your Applications folder. Open it from there.

Review macOS prompts

This build is not Apple-notarized. After a blocked launch, only if you trust the download, use System Settings → Privacy & Security → Open Anyway. Keep macOS security protections enabled.

Complete Android setup

Follow the app’s setup instructions, review the runtime terms, and let the required Android downloads finish. Select Start Android.

Install your Android app

Choose Install an APK, select a compatible APK you trust, and open the installed app inside the Android window.

A lighter starting point

Give Android room to run.

DISPLAY

Start at a lower resolution

Try 960 × 540 when available. Fewer pixels can reduce graphics work, especially on memory-limited Macs.

MEMORY

Leave space for macOS

Start with a lighter memory preset on an 8 GB Mac. Close heavy browser tabs and other virtual machines.

WORKSPACE

Use Focus mode

Reduce dashboard activity while Android is running. Stop Android before changing presets, then restart it.

Performance depends on your Mac, graphics support, Android image, and workload. No fixed frame rate or lag-free operation is guaranteed.

Understand what you install

Privacy and safety, explained.

Your Android session

OrbitDroid provides a dashboard around Google’s Android Emulator. Emulator data and installed apps are stored on your Mac. Android apps and Google services can make their own network requests.

Install APKs from sources you trust. Review permissions and the privacy policies of the apps you install inside Android.

Know the build’s status

This Mac build is not Apple-notarized and has no independent malware-free certification. Download from the official repository and compare published checksums when available.

This page contains no analytics scripts, external fonts, or account forms. GitHub handles hosting and download requests under its own policies.

Open source allows inspection; it does not guarantee that software is free of bugs or security issues. Keep your Mac updated and avoid installing untrusted APKs.
Help when you need it

Common questions.

Which ZIP should I download?

Choose OrbitDroid_Mac_Apple_Silicon.zip for an M-series Mac or OrbitDroid_Mac_Intel.zip for an Intel Mac. Extract it and move OrbitDroid.app to Applications.

The download button gives a 404 error.

The matching app ZIP has not been uploaded at the configured release address, or its filename or tag is different. Open GitHub Releases and check the available assets. The website owner must make the button URL match the exact release tag and asset filename.

Apple could not verify the app. What does that mean?

The build is not Apple-notarized. Only if you trust the download, use the app-specific Open Anyway option in System Settings → Privacy & Security after attempting to open it. Do not disable Gatekeeper system-wide. If macOS reports malware or damage, stop and contact support.

Why is Android slow?

Try a lower display resolution, a lighter memory preset, and one Android device at a time. Close heavy apps and ensure there is enough free disk space. Some Android apps are demanding or do not support emulators well.

Does OrbitDroid support every Mac?

No. Separate Apple silicon and Intel builds are available, but macOS 13 or later and compatible virtualization are required. Support across every Mac model has not been verified.

Does open source mean all Android apps will work?

No. App compatibility depends on the Android image, processor architecture, graphics support, and the app’s own requirements. Some games, DRM services, and anti-cheat systems reject emulators.

Can I use Google Play?

Google Play availability depends on the installed Android system image. Google services have their own terms and privacy policies. The app does not guarantee Play certification.

How do I uninstall OrbitDroid?

Stop Android, quit OrbitDroid, and move OrbitDroid.app from Applications to the Bin. This may leave virtual-device data and downloaded runtime files on your Mac. Back up anything important and consult the project’s instructions before removing those files.

How do I report a problem?

Email Rahul or open a GitHub issue. Include your Mac chip, macOS version, OrbitDroid version, the exact error, and the steps that caused it. Remove passwords, tokens, and personal information from logs and screenshots.
