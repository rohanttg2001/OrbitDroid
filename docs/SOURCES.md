The project's own feature/license/privacy notes were checked against the existing
OrbitDroid 0.4 source and release documentation. Those application sources and
private signing material are not included in this public README ZIP.

Screenshots and the annotated PDF were supplied by the user. They show earlier
builds and example macOS dialogs. They are not a new native benchmark or a
security scan of 0.4. Earlier Community screenshots show MIT/open-source wording;
the current Free/Pro text and existing MIT permissions are distinguished on the page.

The installation and macOS GIFs are original code-drawn illustrations, not screen
recordings. They intentionally avoid invented FPS, download timings, payment
confirmations or customer keys. The generated emerald landscape is decorative brand artwork. The README header and information cards are original code-drawn graphics.
