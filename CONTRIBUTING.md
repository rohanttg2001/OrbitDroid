# Help improve the public guides

This repository contains OrbitDroid's README, artwork and public documentation.
Suggestions, corrected instructions and reproducible bug reports are welcome.
The private application source is not included here.

For a bug, include the app version, Android version, Mac chip, macOS version,
the steps you tried and the exact error. Redact keys, Device IDs, account details
and private paths from any screenshots or logs. Do not upload a whole app-data
folder. Use the Bug report issue template when available.

For privacy/security concerns, payment, Pro licensing or source access, contact
**rohan1ttg2001@gmail.com** privately. See [SECURITY.md](SECURITY.md).
